TrineEvo Backend Theme

A modern responsive backend UI theme for the standard Odoo web client. The module improves presentation only and keeps Odoo features, security, workflows, models, actions, menus, and business data unchanged.

Highlights

  • Clean app launcher, navigation, control panel, forms, lists, kanban, pivot, graph, and dialog styling.
  • Accessible focus states, responsive spacing, and browser-only theme density preferences.
  • No external dependencies, dashboards, controllers, models, security files, or app-specific assumptions.
